# CTS 首页、Tailor Made、Golden China 本地验收版

## 范围

- 首页保留正式品牌、导航与原有模块，缩短首屏并加入城市 / 月份 / NZD 人均预算搜索和体验入口。
- `/tours/find` 是首页搜索的必要配套：直接读取正式产品、未来团期及对应团期价格，支持组合筛选，保留原来的关键词 / 国家 / 兴趣 / 标签入口。
- `/tailor-made` 使用两步传统表单；旅行想法与联系方式分开，返回不会丢失输入。可预填体验或灵感卡片，日期可选灵活 / 月份 / 指定日期。继续使用 `/api/tailor-made-enquiry` 和既有提交统计。
- `/tours/china/discovery/golden-china` 为唯一详情页试点：照片轮播及键盘 / 触屏查看、原有桌面和手机地图、可展开完整行程、日期与人数询价、相关旅游及站内指南。
- AI Beta 未开放。其他 Tour 与 campaign 页面没有切换模板。

## 共享模板的明确例外

用户要求先选一个 Tour 更新，因此 Golden China 使用独立展示组件；其他详情及广告页保留原共享模板。Golden 继续使用原始产品数据、canonical、结构化数据、TrustBar、TourTrustSignals、TourInclusions、TourSupportingContentLinks、FAQSection 和 TourEnquiry。TourEnquiry 新增的上下文 / 紧凑展示参数均为可选，不改变旧调用的默认行为。

## 数据与素材

- 所有价格、团期、行程、包含 / 不含项目继续来自 `src/lib/data/tours.ts`，没有部署静态预览的产品快照。
- 体验映射保留证据和审核日期；只有现有产品 highlights 仍匹配证据时，才标为已包含。Universal Beijing 仅进入定制咨询。
- 本地图片来自已获选的预览素材副本，输出优化 WebP，保留原图。外部 CTS 图片使用正式图片加载器所需的标准源 URL。
- 筛选将日期按 Auckland 当天判断。首页缓存每小时更新，原 Tour 页面缓存策略保留。
- 生产业务联系方式、导航、产品 URL、元数据及询价接口保留。

## 验证

- TypeScript 检查通过。
- Jest：43 suites / 547 tests 全通过，包含组合月份与预算匹配同一团期、过期团期排除、无团期产品、体验证据失效、Auckland 日期边界。
- 浏览器桌面及 390px 手机：三页和搜索结果无横向溢出 / JS 异常。
- 检查首页搜索到结果页、无结果状态、定制预填与两步往返、错误后重试、轮播 / 模态框 / 键盘、完整 Forbidden City 限制说明、Tour 日期人数询价内容。
- 询价测试在浏览器拦截 API 并验证 payload，未发送实际邮件。现有本地环境未配置邮件服务，因此尚未验证真实邮件投递。
- `npm run lint` 当前会进入仓库原有 ESLint 首次配置提示，未作为通过项；生产构建包含 TypeScript 校验。

## 后续验收调整：少量产品的搜索体验

- 首页下拉选项按其他当前条件显示匹配团数，零结果时提供 close alternatives 入口；也可直接点击近期行程。
- 无精确匹配时，保留城市、体验、国家及原有关键词 / 兴趣 / 标签约束，仅放宽日期和预算，并逐卡显示差异。无相关行程时仍可携条件进入定制咨询。
- 定制表单接收搜索的城市、月份、人均预算和其他偏好；月份保持月份，不转换成确定的 1 日出发。
- 体验区将 Universal 替换为北京皇城 / 故宫，映射核对现有产品 highlights，明确门票供应限制。Universal 的旧定制链接仍可使用。
- 再验证：43 suites / 550 tests 全通过，生产构建通过；浏览器验证北京 / 2026-11 / NZ$3,000 的替代行程、差异标注、条件不变与定制预填，以及手机无横向溢出。
